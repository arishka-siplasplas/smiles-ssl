Downstream-качество и ранг на одном графике

Как в примере: чёрная линия показывает качество, оранжевая — выбранную ранговую метрику. Строки — три SSL-метода, столбцы — precision аномального класса и ROC-AUC.

Последняя завершённая серия: 54 SSL-запуска, 3 seed, эпохи 0 / 1 / 2 / 5 / 10 / 20 / 30. Каждая линия — среднее по seed. Точки соединены прямыми отрезками без сглаживания.

Автономный отчёт: все 192 графика и таблицы встроены в этот HTML. Можно переслать один файл и открыть его в браузере без интернета.

Вид 0–1 сравнивает форму траекторий: сначала берётся среднее по трём seed, затем каждая линия отдельно преобразуется по формуле (значение − минимум) / (максимум − минимум) за все семь checkpoint. Направление кривых сохраняется. Высота и расстояние между линиями не показывают равенство исходных значений или силу связи.

Что именно измеряется

Обе линии рассчитаны на фиксированном официальном test выбранной категории. Epoch 0 — необученный ResNet-18. Классификаторы переобучались на замороженных признаках на каждой оценочной эпохе. Их параметры и порог выбирались только на validation; новых подборов параметров для этих графиков нет.

Precision относится к аномальному классу. Порог выбран при validation recall ≥ 0.5, но это ограничение не гарантировано на test. ROC-AUC не зависит от выбранного порога.

Raw/L2 меняет только расчёт рангов. Оба классификатора используют raw-признаки. В режиме исходных значений серая и оранжевая полосы — ± выборочное стандартное отклонение по трём seed, а не доверительный интервал. У качества левая ось, у ранга — правая; шкала ранга общая для всех шести панелей.

RankMe, CER, CovER и NESum используют определения исходного эксперимента. Min–max для отрисовки — отдельное преобразование, не L2-нормировка эмбеддингов.
